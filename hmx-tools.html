Pipeline Tools @ HMX

What it does

            
Every 3D team has repetitive work that eats into the time for the actual 3D. I build small tools that take it off the team's plate.
I write them with AI as a co-pilot. Knowing the 3D side means I know what to ask for and how to check what comes back, which makes them quick to build.

          


          

          

            
What I built

            

              
AR project setup tool

              
does
Gets a new AR project set up and ready to work on.
result
~30–40% less time

            

              
Blender add-on for AR

              
does
Brings common fixes for AR assets together in one place.
result
~30–40% less time

            

              
Blender add-on for real-time work

              
does
Does the same for real-time assets.
result
~30–40% less time

            

              
File and screenshot tool

              
does
Speeds up repetitive file work and screenshots.
result
~30–40% less time

            

            
Plus a steady stream of Blender Python scripts for my own work, whenever something repeats.
