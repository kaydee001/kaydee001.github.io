## How it's built

A static site with no framework, served by GitHub Pages.

- **3D hero:** [three.js](https://threejs.org/) with a toon-shaded model (`viewport.js`, models in `models/`)
- **Motion:** [GSAP](https://gsap.com/) with ScrollTrigger, and [Lenis](https://lenis.darkroom.engineering/) for smooth scrolling
- **Contact form:** [Web3Forms](https://web3forms.com/) with hCaptcha
- **Themes:** dark and light, following your system setting until you pick one

The HTML pages are generated by a Python script, so edit that rather than the HTML:

```
python -I _build/build_v4.py .
```

| Path | What it holds |
|---|---|
| `_build/build_v4.py` | The page generator: layout, copy, client work and case studies |
| `_build/build.py` | Project data (names, stacks, links) |
| `_build/renders.json` | The 3D renders shown in the gallery |
| `_build/capture_viewer.py` | Captures product shots from 3D viewers |
| `script.js`, `styles.css`, `viewport.js` | Behaviour, styles and the 3D hero |
| `images/`, `models/` | Images and 3D models |
