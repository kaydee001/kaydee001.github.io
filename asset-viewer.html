[03] Tool · case study

              
Asset Viewer

              
A 3D model viewer that runs on your own machine. Drop in a model and inspect it: no uploads, no accounts.

              
GitHub ↗

            

            
type
Tool
stack
Three.js · Flask · PyQt5 · PyInstaller
runs on
Windows (.exe)

          

        

      


      

        

          

          

            
What it does

            
Drag in a GLB, GLTF, FBX or OBJ and it loads straight away. It shows the mesh stats you usually go looking for and gives you the basic inspection tools: orbit and pan, wireframe, a grid and HDRI lighting with presets or your own HDRI.
It ships as a standalone Windows app, so nobody needs Python installed to use it.

          


          

          

            
How it's built

            
  1. renderThree.js does the 3D: loading the formats, lighting, orbit controls, wireframe and grid.
  2. serveA small Flask server hosts the viewer locally, so files never leave the machine.
  3. wrapPyQt5's QWebEngine turns it into a desktop window instead of a browser tab.
  4. shipPyInstaller packages everything (the viewer, HDRIs and sample models) into a folder with an .exe.
